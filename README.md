# DeM Modas (exemplo)

Este repositório contém um site estático de exemplo para a loja "DeM Modas" com tema rosa.

Arquivos principais:
- index.html — página principal
- styles.css — estilos

Como ver o site localmente:
1. Abra o `index.html` no navegador (duplo clique) ou use um servidor estático como `live-server`.

Publicação (GitHub Pages):
- Em repositórios públicos, o GitHub costuma publicar automaticamente a partir do branch `main` quando existe um `index.html` na raiz.
- Link esperado: `https://matheusdiniz111111-lang.github.io/dem-modas/`
- Se o site não aparecer automaticamente, vá em Settings → Pages e selecione o branch `main` e a pasta `/ (root)`.

Como editar:
- Faça alterações nos arquivos no GitHub ou clone o repositório localmente, edite e faça push.
